# Included source copies

[Guide home](../README.md) · [Script index](../ScriptReference/README.md)

This folder contains 226 original C# source snapshots organized under their original Assets paths. The live project was not edited. Chapter links provide both the current project path and these portable copies.

These are study copies, not a separate Unity project. Do not copy this entire folder into Assets, which would create duplicate class definitions. Supporting asset values, input actions, name tables, and beatmaps are in SourceData. `source-manifest.json` records source hashes.
