## What an FSM is

A finite state machine chooses one named state and performs that state's behavior. Your encounter enemy has Idle, Patrol, Chase, Attack, and OutOfSight. Transitions reset relevant timers and pending attack impact.

| State | Behavior and exit |
| --- | --- |
| Idle | Waits stationary; after three seconds, tries a patrol destination. |
| Patrol | Moves toward a seeded random reachable point near home; returns to Idle on arrival/timeout. |
| Chase | Repaths toward the detected player. |
| Attack | Stops, faces the player, winds up, and checks/launches an impact. |
| OutOfSight | Stops and visibly searches left/right; returns to Idle after about 1.5 seconds. |

## Navigation and detection

NavMeshAgent follows valid paths rather than walking in a straight line through obstacles. Patrol samples a random point within home radius and requires a complete path. Chase is not restricted to that patrol radius. Detection considers height/range, with extra tracking tolerance. A line-of-sight ray rejects blocked attacks. Water terrain is excluded from generated exploration navigation.

## What starts combat

Skeleton's actual melee impact must overlap the active character. Minion launches EncounterProjectile; actual projectile collision starts the battle. Moving out of range or behind a blocker can cancel/intercept the hit. Merely seeing the enemy is not itself the battle trigger.

## Battle variants

Veterans are larger/purple with enemy red highlighting. Skeleton veteran attacks three times with post-defense scales 1, 0.5, and 0.25. Minion veteran fires two projectiles. Damage has a minimum of one, so tiny later hits still deal one.

BattleEnemyMotion handles procedural sword/body/recoil feedback around the imported models. Settings provide attack/laser sounds. Stable encounter identities let BattleSession remember defeated enemies across chunk reloads and saves.

For FSM explanation, name both the **condition** that changes state and the **action** performed in the state. Listing five labels alone does not explain the machine.

void SetState(State value)
{
    if (CurrentState == value) return;
    CurrentState = value; timer = 0; nextPath = 0; impactAt = -1;
    if (value == State.OutOfSight) confusedFacing = transform.rotation;
    if (value == State.Idle || value == State.OutOfSight) StopMoving();
