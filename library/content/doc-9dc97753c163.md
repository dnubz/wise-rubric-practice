# The shared molecule and dungeon naming algorithm

**Workbook areas:** `IUPAC Algorithm`, `Dungeon`, `Minigame`.

## What is shared

`BerdlyMolecule` stores nodes (carbons/rooms), undirected bonds (connections/doors), and drawing coordinates. `BerdlyChemistry` generates questions and names graphs. DungeonLayout reuses SelectChain/Name to divide a dungeon into chains and name it.

The code follows the project's alkane/alkyl notation, including its hyphen before the parent alkane. This chapter explains that implementation, not a claim to cover every chemical IUPAC rule or molecule type.

## Building a question graph

A random walk collects unique grid points. Adjacent grid points get random-weight edges. Kruskal sorts them and joins only different disjoint sets, creating a connected acyclic carbon tree. Question generation rejects unsuitable/simple-branch limits with bounded retries and has a known fallback tree.

## Naming, step by step

1. `BestPath` considers possible endpoints within the selected component.
2. Prefer the longest chain, then branch/locant tie-breaks.
3. For the top-level chain consider orientation so branch locants favor the earlier/lower arrangement.
4. For each off-chain connected component, recursively call NamePart from its attachment root.
5. Group identical branch names, collect their one-based positions, and apply multiplier prefixes.
6. Sort branch-name groups and append the parent alkane from the naming table.
7. A nested branch name is wrapped in parentheses using the project's recursive notation.

The maximum selected chain is 11. `LongestChainLength` uses tree-distance searches to detect the diameter length, but the actual tie-breaking chain selection comes from BestPath. Do not confuse the longest-length helper with the full numbering algorithm.

## A small worked example

Imagine a five-carbon parent path with a one-carbon side branch at the second carbon. The table supplies `pentane` and `methyl`; numbering gives locant 2; the project's naming output is `2-methyl-pentane`. Reversing that drawing must still prefer locant 2 over 4. Drawing coordinates do not define the name: bonds do.

## Wrong answers

MakeQuestion creates nearby graph mutations by adding one carbon, names them, removes duplicates/correct matches, and shuffles three distractors plus the correct answer. Very small molecules supplement distractors with nearby alkanes. Distractors are generated data, not four hardcoded button labels.

Dungeon “degree 1” is the parent naming chain; degree 2/3 means recursively nested branch chains, not carbon bond degree.

## Small piece of the actual code

From [BerdlyMolecule.cs](<C:/Users/Ezell/WiSe/Assets/Scripts/UI/InGame/BerdlyMolecule.cs:205>) (line 205). This is an excerpt; continue in the full script for context.

```csharp
string NamePart(BerdlyMolecule molecule, HashSet<int> included, int root)
{
    var chain = BestPath(molecule, included, root);
    if (chain.Count > MaximumChain)
        throw new ArgumentException("The longest carbon chain cannot exceed " + MaximumChain + ".");
    var groups = new SortedDictionary<string, List<int>>(StringComparer.Ordinal);
    var onChain = new HashSet<int>(chain);
    for (int i = 0; i < chain.Count; i++)
        foreach (int neighbour in molecule.Bonds[chain[i]])
        {
            if (!included.Contains(neighbour) || onChain.Contains(neighbour)) continue;
            var branch = Component(molecule, neighbour, included, onChain);
            string name = NamePart(molecule, branch, neighbour);
            if (!groups.TryGetValue(name, out var positions)) groups[name] = positions = new List<int>();
            positions.Add(i + 1);
        }
    if (groups.Count == 0) return root < 0 ? alkanes[chain.Count - 1] : alkyls[chain.Count - 1];
```
