# WiSe feature learning guide

Start here. This folder teaches the current game using the supplied scoring workbook and the actual project code.

1. Read [Learning path](00-learning-path.md) to choose a manageable order.
2. Keep [Controls](01-controls.md) open while demonstrating the game.
3. Read a chapter below: player behavior → code flow → actual snippet → demonstration → a short explanation you can say aloud.
4. Open its linked project script or the included copy.
5. Use [Workbook and scoring](02-workbook-and-scoring.md) and the [rubric index](Rubric/README.md) to cover every requirement.

## Read the known gaps

The current pool center creates a glide cliff and chest instead of the required boat/deck. The audio mapping has three dry walking clips and swimming audio, but no distinct water walking clip. Rain/blossom weather and title character/Play animations need direct inspection. Read [verification and gaps](Features/30-verification-and-gaps.md) before describing the project as complete.

No gameplay code or workbook content was changed. The script copies reflect the local working tree at documentation time, including existing BattleCamera/BattleController edits. No new Unity playtest/build was run for this documentation task.
